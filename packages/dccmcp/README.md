# dccmcp

**Command line for DCCMCP** — MCP servers for creative and engineering software.

> **Status: not released yet.** This package name is reserved by DCCMCP. Running it today prints a
> status message and exits.

## Install

```bash
npx dccmcp --help
```

## Integrations

Install a host application integration directly instead:

```bash
npx dccmcp-blender serve
npx dccmcp-maya serve
npx dccmcp-houdini serve
npx dccmcp-3dsmax serve
npx dccmcp-rhino serve
npx dccmcp-zbrush serve
npx dccmcp-photoshop serve
npx dccmcp-freecad serve
npx dccmcp-qgis serve
```
