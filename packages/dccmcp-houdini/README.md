# dccmcp-houdini

**MCP server for Houdini** — let AI agents work inside a real Houdini session with typed
tools, safety policies, checkpoints and audit logs.

> **Status: not released yet.** This package name is reserved by DCCMCP. Running it today prints a
> status message and exits.

## Install

```bash
npx dccmcp-houdini serve
```

## Documentation

- Integration page: https://dccmcp.com/mcp-for-houdini
- Install and client setup: https://dccmcp.com/docs#quickstart
- Works with Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Doubao, Qwen Code, Trae and any
  other MCP-compatible client.
